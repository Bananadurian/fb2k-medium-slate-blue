Help overview

Panels Tree context menu

The Panels Tree is shown when the popup contains a panel container. It displays the container's nested panel layout. Right-clicking a tree node selects that node and opens its context menu. Right-clicking empty tree space opens the menu for the root container.

Right-clicking empty tree space

Add child
Adds a panel to the root container. The submenu lists available extensions grouped into Containers, Panels, Playlist views, Toolbars, and Visualisations.
Paste
Appears when the Panels Tree clipboard contains a copied or cut panel. It adds that panel to the root container.

Right-clicking a panel node

Insert Before
Adds a selected extension immediately before the node in the same parent container.
Insert After
Adds a selected extension immediately after the node in the same parent container.
Replace
Replaces the selected node with a selected extension.
Remove
Removes the selected panel from its parent container.
Cut
Places the panel and its configuration on the Panels Tree clipboard for moving it. The source panel is removed when the cut entry is pasted.
Copy
Places the panel and its configuration on the Panels Tree clipboard without removing the source.
Paste
Is available for a container node when the clipboard has a panel. It adds the panel as a child of that container. Non-container nodes cannot contain pasted children.
Move Up and Move Down
Reorder the node among its siblings in the same parent container. Each command is offered only when a sibling position exists in that direction.
Add child
Is available for a Containers node. Its submenu adds an extension inside that container; available extensions are grouped by category.

The Panels Tree clipboard is shared between Configure dialogs. You can therefore cut or copy a panel node in one dialog and paste it into a compatible container in another dialog. Cutting removes the source node when pasted; copying leaves the source in place. Paste is available on the root container or on a container node.

Insert, replace, remove, move, cut, and paste operations update the tree and the popup's saved panel configuration.
