Help overview

Main menu commands

Open View > Popup panels to manage popup windows. The available entries depend on the extensions installed in foobar2000 and exposed through Columns UI.

New panel

Choose a panel from New panel to create a popup window for it. Available entries are grouped by category, such as Containers, Panels, Playlist views, Toolbars, and Visualisations. The new window uses the current default values from the Popup Panels preferences.

Show and configure

Show contains an entry for each existing popup. Its checked state indicates whether the window is visible; selecting it toggles that window. Configure opens the settings for the corresponding popup. Show all panels and Hide all panels change the visibility of all existing popups.

Panel context menu

When the popup has a title bar, right-click its title bar and choose Configure popup... to open its configuration dialog. The popup configuration command may also be available from the hosted extension's context menu when that extension supports it.

For container panels, the configuration dialog also includes the Panels Tree, where its context menu can be used to edit the container's panel layout.
